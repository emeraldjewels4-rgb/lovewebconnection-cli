Every currency /api/markets carries, in the position it publishes — one response for the whole list, not one request per coin. The table above is a different set: the seventeen chains this host reads from MySQL. Every row links to Blockchair where that chain is supported there, including Monero; the rest link to their CoinGecko market page. Where the host reads the chain, the row also carries that chain's latest Blockchair block height and mempool from /api/web9999/coins, so the market list needs no per-row request.
